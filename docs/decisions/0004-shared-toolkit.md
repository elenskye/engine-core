# 0004 共用 Toolkit 执行调用流程

2026-11-27 站主决定；同日本机 Claude 审核时补了两步调用和错误补齐。

- `Toolkit` 统一处理取消、参数、报价、确认和结果校验。引擎注册执行函数，计费工具另注册本地数单位的函数；执行时收到的就是确认过的那份报价。
- **分两步**：`prepare` 校验参数、报价、判断要不要确认，`run` 执行；`call` 是两步连着、中间问 `ctx.approve`。App 的确认是界面上的卡片，等用户点要时间，两步调用不用在线程里干等；命令行也靠它只报价不执行。
- **错误说明只写在清单里**：实现交 `ToolError::of(种类)`，Toolkit 照清单的 `errors` 或通用种类补齐说明、建议和能否重试。不然同一句话要在清单和代码里各写一遍，迟早对不上。
- App 的覆盖同时用于清单和调用。无效覆盖整份报错，数值范围和数组长度用参数名及约束关键字收紧。
- 免费及本机工具可配置每次确认。计费工具本次报价为零时直接执行。
