# 0007 查找的折叠和命中

2026-11-27 站主决定前三条；同日本机 Claude 用 38 份真实论文（891 页）和 8 页扫描件核对后改了后三条。

- 仅折叠拉丁字母的重音，保留其他脚本的组合符号。
- 整句按非重叠位置计数，例如用「哈哈」搜「哈哈哈」计一处。
- 按词回退时英文和数字按完整词找，汉字允许子串。重复词需要对应次数的非重叠出现。同一单元取涵盖全部词的最短原文范围。
- **按词时每个词各算一处**：交回最短范围里每个词的位置和前后文，不再把整个范围当一处。真实论文里这个范围常常是半页到一页（Shore 2019 第 2 页约 4,000 字），一处就把整页塞给模型，阅读器也只能把整页高亮。
- **中日文旁的空白去掉**（原来只去两个汉字之间的）：知网论文的换行常在全角标点前后（`，\n２`、`；\n李`、`］\n。`），中西文之间也常有空格。只去两个汉字之间时，模型照着打的句子有约 6% 整句找不到。
- **拉丁字母之间的横线去掉，看不见的字符去掉**：复合词在连字符处换行（`self-\nattention`）原来连词都找不到；有的论文每个词里都埋了软连字符（Arpino 2022 有 4,000 多个，`dis\u{ad}trib\u{ad}uted`），原来整篇大半的词搜不到。改后 `self-attention`、`selfattention`、`self-\nattention` 都折成一样。v0.2.1 起软连字符后跟空格（没有换行）不再当断词：同一批论文里这样的 24 处有 23 处是词间空格（`all\u{ad} observations`、`between-\u{ad} and`），拼起来整句、按词都找不到；只有 Pargent 2023 一段 R 代码（`Socia\u{ad} bleness`）是换行被取成了空格，舍掉。
- 改后核对：从原文随机截 2,413 个片段，原样去找全部在原处命中；「模型照着打」（换行按两边是不是中文变成空或空格、去掉断词）失败率从 6–8% 降到 0.2%，剩下的是核对程序把全角数字当成中文造成的假失败。
