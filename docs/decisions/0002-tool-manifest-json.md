# 0002 工具清单用 JSON 文件，一个工具一份

2026-11-27，本机 Claude 定（设计稿 §1）。

- 每个引擎的工具清单放在 `tools/<名字>.json`，一个工具一份。这一份就是唯一的定义：Rust 用 `include_str!` 编进去并校验，App 读它接线，命令行照它列出和校验参数，TS（比如 engine-pdf 的 `web/`）也能直接读。
- 参数用 JSON Schema 的一个小子集，本库自己校验，不引整套 JSON Schema 库（每个引擎都会带上它，太重）。
- 说明默认用中文写；App 可以按工具名覆盖。

没选的：用 Rust 宏或结构体定义工具再导出 JSON（定义锁在 Rust 里，TS 和 App 只能读导出的副本，容易两份不一致）；TOML（参数本来就是 JSON Schema，换格式多一道转换）。
